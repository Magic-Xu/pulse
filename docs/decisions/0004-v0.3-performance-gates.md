# ADR 0004: Pulse v0.3 Performance Gates

- Status: Accepted
- Target version: 0.3.0
- Scope: release verification

## Decision

The release harness runs the same simple reducer workload against a frozen v0.2 synchronous
reference and the v0.3 ordered engine. It records throughput, p95 frame latency, a bounded-mailbox
admission count, cancelled-subscription memory delta, and a synthetic selector hit count in a
machine-readable JSON report.

Correctness takes precedence over matching the lock-only v0.2 implementation. The portable CI
floor therefore rejects catastrophic regressions rather than normal coroutine overhead:

- v0.3 throughput must remain at least 0.5% of the v0.2 reference workload;
- p95 sequential frame completion must remain below 100ms;
- mailbox high-water must never exceed configured capacity;
- the 10,000-subscription cancel workload must retain less than 64MiB after forced collection.

The mailbox metric is a capacity smoke test, not instrumentation of every internal queue state. The
selector metric is a deterministic arithmetic distinctness fixture; it does not execute the runtime
or Compose selector path and has no pass/fail threshold. The harness is intended to catch catastrophic
regressions on a portable CI runner, not to establish device performance or comprehensive benchmark
evidence.

Release review keeps the full report as an artifact. Tightening a threshold requires measurements on
the same CI runner class and an ADR update; a threshold may not be relaxed silently.
